# AlgoPy

Algorithmic trading using python.
In depth analysis of market data, Data visualization methods and modules and backtesting strategies.

This repository is for educational purposes only.

## Setup

In order to start using this repository, you have multiple ways of setting up your python environment.
The easiest approach I recommend is using `uv`. Simply `cd` to the repo root directory and run:

```bash
uv sync
```

Otherwise your can use the `environment.yaml` file to set up conda, or use the `install.sh` script. This script uses pip and venv
to set up your environment.
